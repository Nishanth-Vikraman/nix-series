# Nix Series

A working paper proposing a combinatorial spectral expansion for nonlinear frequency interactions, accompanied by synthetic experiments. It is a theory-and-simulation proposal, not evidence of validation on a physical device.

[Read the working paper](nix_series_paper.pdf)

The supplied project folder contained the PDF only; simulation code and raw experiment outputs are not included in this repository. The paper contains unresolved citation markers and should be treated as a working draft.
